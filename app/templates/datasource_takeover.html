{% if mode == 'proof' %}

Die API von {{ ds.provider_label }} liefert die Historie seitenweise bis zum Ende und den aktuellen Bestand. Wenn die Vorgänge der API den Bestand exakt ergeben, ersetzt Portfolia die Buchungen des kuratierten Imports (z. B. {% else %}

Bei {{ ds.provider_label }} lässt sich die Vollständigkeit der Historie nicht aus dem Abruf belegen. Wenn du sie bestätigst, ersetzt Portfolia die Buchungen des kuratierten Imports (z. B. Koinly) ab dem ersten Ereignis der Quelle durch die der Quelle – eine Entscheidung statt vieler Einzelkonflikte. Davor bleibt der Import. Als Sicherung gilt: weicht der Bestand eines Assets danach stärker vom beobachteten ab als vorher, wird alles zurückgenommen.

{% endif %}
  • Es wird nichts gelöscht: Import-Buchungen werden ausgeblendet, die Übernahme ist als Ganzes rückgängig zu machen.
  • EUR-Werte und Einordnungen des ersetzten Imports bleiben erhalten, wo die API sie nicht liefert.
  • {% if mode == 'proof' %}Stimmt der Bestand nach dem Buchen nicht exakt, wird alles automatisch zurückgenommen.{% else %}Wird der Bestand nach dem Buchen schlechter als vorher, wird alles automatisch zurückgenommen.{% endif %}
  • Grenzen: Der Nachweis betrifft Mengen, nicht Werte. Realisierte Ergebnisse und Erträge je Steuerjahr werden vor und nach der Übernahme gemessen und im Ergebnis gezeigt (nicht vorab simuliert). Manuelle Buchungen, Transfers mit anderen Konten und Korrekturen bleiben bestehen.
