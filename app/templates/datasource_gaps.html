Was folgt daraus?

  • Lücken belegt und vom Import gefüllt: Die Quellenübernahme lässt diese Import-Buchungen stehen – nichts weiter zu tun.
  • Nur in der alten API, erklärt die Lücke vollständig: Die neue API lässt diese Arten aus; die alte liefert sie (bis {{ legacy_until.strftime('%d.%m.%Y') }}). Den Bericht als CSV weitergeben – daraus lässt sich ableiten, ob die Übernahme diese Einträge bis dahin aus der alten API ergänzen soll.
  • Rest ohne Beleg: weder Import noch alte API erklären ihn – nur mit Ausgleich (Zustimmung je Asset) auf der Übernahmeseite.
